# Architecture decision records

> **Demo disclaimer:** This is a technical simulation on a local chain (Anvil) or a testnet. It is not a real offering and moves no real money.

One file per decision, each with Title, Status, Context, Decision, Consequences and Alternatives considered. Add a new ADR for any decision that would be expensive to reverse, and link it from here. To change a decision, add a new ADR that supersedes the old one and update the old one's status. Related: [open-questions.md](../open-questions.md), [docs index](../README.md).
